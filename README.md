# Nasdaq Macro Shocks Analysis

Final project for Time Series Analysis: combining SVAR and SARIMA/SARIMAX to study NASDAQ-100 under macro shocks.

## Project structure

- data/: raw and processed data lifecycle
- src/: reusable Python modules
- notebooks/: analysis pipeline notebooks
- outputs/: exported figures and tables
- docs/: references and final report artifacts

## Quick start

1. Create and activate a Python environment.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Run notebooks in order from 00 to 06.
